## Fastest path

Download [`docker-compose.yml`](https://raw.githubusercontent.com/ShipLean/docs/feat/docs-site/examples/quickstart/docker-compose.yml) and [`.env`](https://raw.githubusercontent.com/ShipLean/docs/feat/docs-site/examples/quickstart/.env) into the same folder. Set the admin email and password in `.env`, then run:

```sh
docker compose up -d
```

Open `http://localhost:8080` and sign in. When you're ready, [connect Claude Code](/agents/connect/).
