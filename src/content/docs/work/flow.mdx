ShipLean is the record from the first idea through delivery. Keep the goal, evidence, decisions and handoff on the Feature so the next person can continue without relying on files on one machine.

These stage names describe the way you work; they are not all Feature states. In the default workflow, a new idea is **New**, work in progress is **Active**, and completed work is **Closed**. To park an idea, leave it in a Proposed state and explain why in its status line.

## The stages

### Epic: choose an area

Use an Epic for a broad area such as onboarding or search. It groups related Features and can provide lanes on the Features board. See [Epics as areas](/work/epics/).

### Idea: capture the goal

An idea starts as a Feature in the first Proposed state, with a clear goal and an Epic. Search first and reuse a matching Feature. See [Capturing ideas](/work/ideas/).

### Research: keep evidence with the Feature

Ask an agent to investigate the question, then attach the findings, link sources and record the session on that same Feature. This keeps the evidence available to the next person. See [Researching an idea](/work/research/).

### Evaluate: make the decision visible

Use the evidence to go ahead, park the idea with a reason and a condition to revisit it, or remove it. Put the reasoning in the Feature body. See [Validating an idea](/work/validate/).

### Plan: turn the Feature into work

Plan the same Feature by its key. Break it into Features, Stories and Tasks as needed, and keep the briefs and decisions on those items. See [Planning and breaking down](/work/plan/).

### Build: hand off work

People and agents can work from the same backlog. Keep progress, reports and review notes on the work items so another person can pick up the thread. See [Agents doing the work](/work/build/).

### Done: capture what you learned

When the Feature is complete, move it to the first Completed state (**Closed** by default), record the outcome and attach a short retrospective. Carry useful lessons into the next plan. See [Finishing and learning](/work/done/).
