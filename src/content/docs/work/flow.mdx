## What goes here
one diagram: Epic (area) → Idea (a Feature in the Idea state) → Research (evidence attached) → Evaluate (go / park / remove) → Plan and break down → Build (agents and people) → Done (retro). One paragraph per stage, linking to the pages below. The rule that ShipLean is the record from the first idea, so nothing important lives in local files on one machine.
