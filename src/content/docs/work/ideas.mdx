## What goes here
an idea is a Feature in the **Idea** state with a goal, under an Epic. Search first so ideas aren't duplicated. Doing it in the UI and doing it with an agent ("I've got an idea about X"). What the Feature body holds: goal; key facts and decisions; next; open questions.
