The REST API reference is not published yet. Until it is, use ShipLean's MCP tools to automate work. See the [available tools](/agents/tools/) and [connect an agent](/agents/connect/).

MCP clients connect to your instance's `/mcp` address. Sign in through the client when it opens ShipLean's consent page, then review and approve its requested access. For script-based MCP clients, set the MCP server URL in the client and complete its sign-in flow. Do not put a person's password in a script. See [authentication options](/agents/auth/) and [consent](/ui/authorize/).

ShipLean also serves `GET /health`, which reports whether the service is running. Its `publicOrigin` field reports the public address ShipLean can determine for generated URLs; `"unknown: set base_url"` means the only available address is cluster-local and no trusted forwarded public origin is available. Set the instance base URL or correctly configure trusted gateway forwarding before requesting MCP attachment transfer links. See [production gateway setup](/start/production/#set-the-instance-url). The health endpoint is not a work management API. This page does not list any REST endpoints yet.
