The REST API reference is not published yet. Until it is, use ShipLean's MCP tools to automate work. See the [available tools](/agents/tools/) and [connect an agent](/agents/connect/).

MCP clients connect to your instance's `/mcp` address. Sign in through the client when it opens ShipLean's consent page, then review and approve its requested access. For script-based MCP clients, set the MCP server URL in the client and complete its sign-in flow. Do not put a person's password in a script. See [authentication options](/agents/auth/) and [consent](/ui/authorize/).

ShipLean also serves `GET /health`, which reports whether the service is running. Its `publicOrigin` field reports the public address ShipLean can determine for generated URLs; `"unknown: set base_url"` means the only available address is cluster-local and no trusted forwarded public origin is available. Set the instance base URL or correctly configure trusted gateway forwarding before requesting MCP attachment transfer links. See [production gateway setup](/start/production/#set-the-instance-url). The health endpoint is not a work management API. This page does not list any REST endpoints yet, apart from the one below.

## Inspection metrics

`GET /api/projects/{projectId}/inspection-metrics` returns the numbers behind the [Inspection page](/ui/inspection/) for one project, as JSON: the same data that the `inspection_metrics` MCP tool returns. Any member of the project can read it. It takes these query parameters, all optional:

| Parameter | Values |
| --- | --- |
| `range` | `last6` (the default), `quarter`, `lastQuarter` or `all`: the sprints to show. |
| `cut` | `none` (the default), `feature` or `who`: how to split the sprints. |
| `period` | A sprint id of the project. Adds that sprint's tasks and Features. |
| `select` | A task key. Only with `period`. |

A value outside these lists answers `400`. A project you cannot read answers `404`. For automation, use the MCP tool.
