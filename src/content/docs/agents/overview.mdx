An agent is a client connected to ShipLean through MCP. Each connection has its own name in work-item history and comments. It acts as the person who signed in, so it sees only that person's projects and uses that person's project membership.

You can use an agent to:

- capture an idea as a work item;
- search and research an item, then save findings on it;
- plan work and prepare a sprint;
- pick up a task and record progress;
- review project or sprint changes.

The agent's changes stay attributed to its connection name. A gateway connection is different: it acts as the person named by the gateway and has no separate agent identity.

## Supported clients

You can connect ShipLean to Claude Code, Claude Desktop, Claude on the web, or Cursor. Each client uses the same MCP address from your profile. Start with [Connect an agent](/agents/connect/).
