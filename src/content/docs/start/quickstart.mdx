## What goes here
the five-minute path to a running app, nothing else (no clone, no `--build`, no dev setup). A complete, standalone `docker-compose.yml` (published ShipLean image + `postgres:18` + volumes) and `.env` in `examples/quickstart/`, shown inline; the reader downloads two files and runs one command. Set `SHIPLEAN_ADMIN_EMAIL`/`PASSWORD`, `docker compose up -d`, open `:8080`, sign in, create your first project, then remove the two admin variables. `GET /health` to check. Ends with "next: connect an agent" and "next: put it behind TLS".
