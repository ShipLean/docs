## What goes here
the feature list (backlogs at three levels, boards, sprints, taskboard, work items, settings, Jira import, instance admin, agents over MCP). The work item model in plain words: Epics hold Features; Features hold Features, Stories and Bugs; Stories and Bugs hold Tasks; every type has its own states, each in a category (Proposed, In Progress, Resolved, Completed, Removed); story points only; nothing hard-deleted. One diagram of the hierarchy.
