Connect Claude Code to a ShipLean instance, approve the connection in your browser, then ask it to research an idea. The agent can create and update work under its own name. You remain in control of whether it gets access.

## Copy your instance address

Open **Your profile** and copy the instance address shown there. The address must be the same one you use in the browser.

<Shot name="guide-first-agent-address" alt="Your profile showing the ShipLean instance address." />

See [Your profile](/ui/profile/) for connected-agent details.

## Add ShipLean to Claude Code

In a terminal, replace `<base_url>` with the address from your profile and run:

```sh
claude mcp add --transport http shiplean --scope user <base_url>/mcp
```

For example, if the address is `https://planning.example.com`, use `https://planning.example.com/mcp`. `--scope user` saves the server for your user account. This is Claude Code's documented HTTP MCP command form. See [Anthropic's Claude Code MCP guide](https://docs.anthropic.com/en/docs/claude-code/mcp).

## Approve the connection

Start Claude Code in a project directory. When it first contacts ShipLean, it opens a browser page for consent. Sign in if asked, review the client name, host and requested scopes, then choose **Allow**. A first connection requests read and write access. The browser returns you to the agent, which can now use ShipLean tools.

<Shot name="guide-first-agent-consent" alt="ShipLean consent page showing the agent identity, requested access and Allow action." />

You can review or revoke active connections from **Your profile → Connected agents**. See [Connect an agent](/agents/connect/) for client setup and [Authentication options](/agents/auth/) for scope and consent details.

## Ask it to research an idea

Give Claude a concrete idea and ask it to capture and research that idea in ShipLean. For example:

> Illustrative prompt: Research whether new team members can find the right project after they sign in. Search for an existing Feature first. If none fits, create one in the appropriate project. Read existing notes, attach your findings and sources, update the Feature with the key facts and decision, then leave a comment and status update. Ask me before changing anything outside that research task.

The text above is an example prompt, not a transcript or a promise of a particular agent response. Claude should reuse an existing Feature when one fits, or create a Feature in a **New** state, then attach findings and update its work item discussion and status.

<Shot name="guide-first-agent-feature" alt="Feature with research attached and a summary recorded on the work item." />

Open the Feature to review its body, attachments, links and discussion. The agent's writes appear under its client name. See [Features](/ui/features/) and [Example prompts](/agents/prompts/).
