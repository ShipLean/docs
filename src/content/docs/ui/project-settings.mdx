Use project settings to manage details and options shared with everyone in the project. Project admins can edit these settings. Members can view them.

The address is `/p/:key/settings/:tab`, where `:key` is the project key and `:tab` is `general`, `states`, `members`, `sprints`, or `integrations`.

## Overview

<Shot name="ui-project-settings-overview" alt="Project settings General tab showing project details and working days." />

Settings tabs share one draft. Select **Save** to apply changes across tabs, or **Discard** to clear unsaved edits. Changes take effect for everyone in the project.

## Edit project details and working days

On **General**, edit the project name or description and choose the working days used for sprint dates, burndown, and capacity. The project key is read-only after creation. Save your changes from the settings header.

<Shot name="ui-project-settings-general" alt="General project settings with project name, permanent key, and working day choices." />

## Choose a country for public holidays

On **General**, the **Public holidays** section has a country list. Choose a country, or **None**, which is the default. Nothing changes for a project until someone picks a country.

ShipLean takes national public holidays for the chosen country from the free Nager.Date service and refreshes them daily, for this year and next year. Regional holidays are not included. Holidays that fall on one of the project's working days lower the default days available in [sprint capacity](/ui/planning/#enter-capacity-per-person). If the server can't reach the service, the section says "Holiday data isn't available on this server." and no holidays apply.

<Shot name="ui-project-settings-holidays" alt="The Public holidays section of General settings with Australia chosen." />

## Choose an agent for the project

On **General**, the **Agent** section chooses the agent connection, repository URL, and base branch that cloud agents use for this project. Select **None** to turn off cloud agents. See [cloud agent integration](/agents/cloud-agent-integration/#set-up-a-project).

## Configure states

On **States**, choose a work item type and manage its states. You can add or rename a state, change its category, reorder states, or remove one where allowed. To start an agent when an item changes state, add a transition in the board's **Automations** section. See [board settings](/ui/board-settings/#set-up-automations). If you remove a state that a transition names, the transition is marked Invalid until you add a state with that name back. Categories group states as Proposed, In progress, Resolved, Completed, or Removed. ShipLean shows each state's item count and checks whether a state can be removed before you save.

<Shot name="ui-project-settings-states" alt="State settings for one work item type with categories, item counts, and state controls." />

## Manage members

On **Members**, add people by email, change their project role, or remove their membership. Project admins manage settings and members. Other members can plan and edit work. A project must keep at least one admin.

<Shot name="ui-project-settings-members" alt="Project members list with roles and member controls." />

## Choose how sprints are named

On **Sprints & forecast**, **Sprint naming** has two choices. **Year, quarter and number** suggests names such as `2026 Q4 Sprint 3`. **Number only** suggests names such as `Sprint 129`. New projects start with Year, quarter and number. Existing sprints keep their names. The setting applies to the next sprint you create, in the **New sprint** form, in the New project form, and over MCP. Members who can't edit settings see the choice disabled. See [Sprints](/ui/sprints/#sprint-names) for how the names are worked out.

## Set sprint forecast options

On **Sprints & forecast**, set the velocity window, which is the number of ended sprints to average. Leave the velocity override blank to use the calculated average, or enter a value in points. This tab also links to **All sprints**, where you can edit the name, dates, and goal of an individual sprint.

<Shot name="ui-project-settings-sprints" alt="Sprint settings with velocity window and optional velocity override." />

## Connect Jira

On **Integrations**, project admins can save a Jira Cloud or Jira Server/Data Center connection and review import jobs. The token is stored encrypted and is not shown again. The connection is read-only. ShipLean reads from Jira and does not write back.

<Shot name="ui-project-settings-integrations" alt="Project integrations with Jira connection and import job list." />

## Keyboard shortcut

- **Ctrl+S** on Windows or Linux, or **⌘S** on macOS: saves changed settings.
